# 网络测速仪表与平台图标优化设计

## 目标

优化工具页的网络测速视觉反馈：加载状态保持在半圆内，下载和上传阶段的仪表根据实时速率更新；提供 `Mbps` 和 `Mb/s` 两种显示格式；平台延迟卡片使用在线获取并随应用打包的平台官方图标，不再使用自绘近似 Geometry。

## 交互与视觉

### 半圆流动刻度

测速处于“选择国内节点”或“检测平台连接延迟”时，在既有半圆路径上显示流动短刻度。动画通过同一半圆 Path 的虚线偏移实现，不旋转 Path 几何，因此不会绘制到下半圈。下载、上传、完成、取消和不可用阶段停止该动画。

### 实时测速反馈

下载和上传阶段每次收到 `NetworkSpeedTestSnapshot` 的新速率都更新中心数值、下载/上传卡片和指针。指针每次从当前角度平滑过渡至新角度，动画时长小于服务的 250ms 快照间隔。

刻度映射分为两段：0–100 Mbps 为线性区间，100–500 Mbps 为压缩区间。这样低速网络中常见的 10–20 Mbps 波动也会体现为可见的指针移动，同时保留高速网络的可读范围。

### 单位切换

仪表中心显示一个小型 `Mbps ⇄ Mb/s` 按钮，使用当前项目的次级按钮样式和动态主题资源。点击后切换所有测速速率文本的单位写法；数值不换算，因为 `Mbps` 与 `Mb/s` 表示同一计量单位。状态、延迟和测速流程不受影响。

### 平台图标

英雄联盟、抖音、京东、携程和今日头条的图标从各平台官网 favicon 取得一次，保存到 `src/ChronoIsle.App/Assets` 并作为 WPF Resource 打包。工具页使用本地 Pack URI 加载图标，运行测速时不会额外请求图标网络资源。当前平台延迟探测 URL 不变。

## 实现边界

- 修改测速面板 XAML、对应代码后置文件、资源清单、平台图标资源和针对性测试。
- 保持现有主题动态颜色、测速服务、节点选择、延迟卡片布局与取消行为。
- 不新增运行时图标下载逻辑，不改变测速数值的单位或计算方式，不修改其他工具页功能。

## 验证

- 新增/更新 UI 合约测试：流动刻度使用半圆路径且只在加载阶段启动；指针基于实时测速阶段和新的两段映射；单位按钮、两种标签和所有本地图标资源存在。
- 执行网络测速服务与 UI 合约的定向测试。
- 发布 Release 并替换运行进程，校验进程可响应且构建 DLL 与发布 DLL 的 SHA-256 一致。
