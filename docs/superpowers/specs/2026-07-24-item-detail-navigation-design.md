# 事项详情定位设计

## 目标

在灵动岛的日历日程和今日概览事项卡片中点击某一事项时，打开事项管理并定位到对应行。

## 交互

- 仅有实际事项的行可点击；空状态保持静态。
- 日历日程中的删除、完成按钮维持原有行为，不触发跳转。
- 今日概览中的下一行动和逾期事项按事项行分别响应点击。
- 事项管理刷新后滚动到目标项，并以两次短暂的边框高亮提示目标。

## 数据流

灵动岛发出包含事项 ID 与类型的详情请求；应用层打开主窗口和事项管理窗口；管理窗口保存待定位目标，在加载/刷新完成后查找事项行、调用 `BringIntoView`，再执行高亮动画。

## 范围

不改变事项数据、排序、删除、完成或焦点逻辑；找不到目标项时仅正常显示事项管理。
