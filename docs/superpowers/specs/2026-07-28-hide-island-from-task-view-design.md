# 灵动岛从任务视图隐藏设计

## 目标

让新旧两种灵动岛窗口都不出现在 Windows 任务视图和 Alt+Tab 列表中，同时保持桌面显示、置顶、拖拽、点击、展开收起和托盘重新显示行为不变。

## 方案

保留两个窗口现有的 `ShowInTaskbar="False"`，并在窗口句柄创建后添加 Windows 原生扩展样式 `WS_EX_TOOLWINDOW`。

修改范围仅包括：

- `LifeIslandWindow`
- `DynamicIslandWindow`
- 与窗口样式设置直接相关的验证

不修改普通主窗口、设置窗口、事项管理窗口或其他弹窗。

## 实现约束

- 在窗口句柄可用后读取现有扩展样式，再按位加入 `WS_EX_TOOLWINDOW`，不得覆盖其他扩展样式。
- 兼容 32 位和 64 位进程的窗口长指针 API。
- 不创建隐藏 Owner 窗口，不引入新的窗口生命周期关系。
- 不改变 `Topmost`、`ShowActivated`、窗口位置或现有事件处理。

## 验证

- 构建应用并运行相关自动化测试。
- 静态确认新旧两个灵动岛都应用工具窗口扩展样式。
- 发布应用后启动验证：灵动岛仍正常显示，但不再出现在任务视图和 Alt+Tab 中。
- 替换当前程序前先确认安装目录和运行进程；关闭旧进程、替换文件并重新启动。
