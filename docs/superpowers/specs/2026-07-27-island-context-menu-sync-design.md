# 灵动岛菜单、顶部自动收缩与折叠态视觉开关设计

## 目标

更新折叠态灵动岛的右键菜单，使其覆盖当前五个页签与设置入口，并提供可持久化的“顶部吸附自动收缩”开关。设置页的七个折叠态显示选项改为直接呈现灵动岛中的真实视觉元素，不再使用可见文字标签。

## 菜单结构

右键菜单保持单层结构，按分隔线划分四组：

1. 快捷创建：新建事项、添加提醒、专注模式。
2. 页面入口：今天、月历、状态、音乐、快问。
3. 管理入口：事项管理、设置。
4. 状态控制：暂停提醒、勿扰模式、顶部吸附自动收缩。

“问 AI”更新为“快问”。页面入口先展开灵动岛，再调用对应的现有 `Show*Dashboard` 方法；快问打开后聚焦输入框。设置继续调用现有设置窗口入口。

## 偏好与兼容

在 `LifePreferences` 参数末尾追加：

```csharp
bool IslandTopDockAutoFold = true
```

旧 JSON 缺少该属性时由默认参数得到 `true`，保持当前顶部吸附后自动收缩的行为，不新增迁移文件。

## 自动收缩状态流

- 菜单项为可勾选项，每次打开右键菜单时从最新偏好刷新勾选状态。
- 关闭时立即保存偏好；如果当前已经收缩，则恢复完整灵动岛，并停止等待收缩的顶部悬浮退出计时器。
- 关闭后，鼠标离开顶部灵动岛不再触发收缩。
- 重新开启时只保存偏好，不立即收缩；鼠标下一次进入并离开顶部灵动岛后恢复现有收缩流程。
- 媒体播放、展开态、鼠标悬浮和非顶部位置等现有收缩条件继续生效。
- `SetTopDockFolded(true)` 作为最终保护入口再次检查偏好，避免其他调用路径绕过开关；`SetTopDockFolded(false)` 始终允许恢复。

## 菜单状态

“勿扰模式”和“顶部吸附自动收缩”显示勾选状态。菜单打开时同步当前服务状态与最新偏好，避免外部设置变化后显示过期状态。

## 折叠态视觉开关

设置页“折叠态显示”区域改为一条迷你灵动岛，七个现有 `CheckBox` 保留原名称和保存逻辑，但使用统一的无文字视觉模板：

- `IslandShowMascot` 使用项目现有 `Assets/island-mascot.png`。
- `IslandShowStatusLight` 使用灵动岛现有事项状态点。
- `IslandShowAgendaSummary` 显示与折叠岛一致的摘要示例“今天暂无安排”。
- `IslandShowNetworkSpeed` 显示与折叠岛一致的网速示例。
- `IslandShowNetworkStatus` 复用当前四节点网络矢量路径。
- `IslandShowClock` 使用折叠岛时间字体和字号。
- `IslandShowExpandIndicator` 使用折叠岛现有展开箭头。

七个元素按折叠岛顺序排列在使用 `Brush.Island`、`Brush.Stroke` 和同等圆角语义的容器中。已选择项保持正常不透明度并显示强调色轮廓，未选择项降低不透明度；实际元素尺寸不因选中状态改变，避免点击时布局跳动。每个元素保留文字 `ToolTip` 和自动化名称供辨识及无障碍使用，但界面不显示原有“吉祥物、时间”等标签。

## 测试

- 旧偏好 JSON 缺少新字段时自动得到 `IslandTopDockAutoFold = true`。
- 右键菜单包含今天、月历、状态、音乐、快问、设置和顶部自动收缩入口。
- 五个页面入口都先调用 `Expand()`，再打开对应页签。
- 自动收缩菜单项可勾选，并在菜单打开时刷新状态。
- 关闭开关会持久化 `false`、停止计时器并立即调用 `SetTopDockFolded(false)`。
- 所有尝试进入顶部收缩态的路径都受偏好保护；恢复展开不受限制。
- 设置页保留七个现有开关名称，但不再包含原有七个可见文字标签。
- 视觉开关使用项目吉祥物资源、四节点网络矢量、动态主题资源和统一选择状态模板。
- 运行两个现有测试项目，覆盖发布 win-x64 自包含测试版并启动目标 `ChronoIsle.exe`。

## 非目标

- 不增加二级菜单。
- 不根据媒体或监控状态动态隐藏菜单入口。
- 不修改设置窗口、托盘菜单、双击、拖动、悬浮宽度或底部吸附行为。
