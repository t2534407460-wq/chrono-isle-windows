# 灵动岛状态图标与交互稳定性设计

## 范围

本轮只调整灵动岛的折叠态网络图标、顶部吸附悬停行为、摘要轮播宽度和展开态设置按钮位置，不改变偏好数据格式、事项状态语义或现有双击操作。

## 视觉与布局

- 将折叠态网络状态圆点替换为约 `12×10px` 的三节点、两连线矢量图。
- 整枚网络图标随网络状态使用成功、警告、错误或禁用颜色；事项状态继续使用现有圆点，因此两种状态可通过形状直接区分。
- 事项与网速同时启用轮播时，摘要区域使用固定 `160px` 宽度并保留省略显示，避免每 5 秒切换内容时改变窗口宽度。仅启用一个摘要来源时继续按内容计算宽度。
- 将“⚙ 设置”从“今天”页快捷操作栏移除，放到展开态标签栏最右侧并右对齐；点击行为保持不变。

## 顶部吸附交互

当前顶部折叠条在鼠标进入时立即移动窗口展开，窗口位移可能产生瞬时 `MouseLeave`，随后又立即折叠并再次触发 `MouseEnter`，形成闪烁循环。

新增独立的短时悬停离开定时器。鼠标进入时取消待处理的折叠并只展开一次；折叠态顶部窗口收到离开事件时不立即折叠，而是在短暂延迟后确认鼠标仍在窗口外才折叠。自由位置、任务栏位置和已展开内容的五秒收起逻辑保持不变。

## 验证与发布

- UI 契约测试验证网络矢量结构、独立状态画刷、设置按钮位置和快捷操作栏中不再出现设置按钮。
- 回归测试验证轮播启用时使用固定摘要宽度，以及顶部吸附采用延迟确认而不是立即折叠。
- 运行核心测试和 UI 测试后，覆盖现有 `Release/net8.0-windows10.0.19041.0/win-x64/publish` 测试版目录。
- 关闭旧版 ChronoIsle 实例，启动新发布的 `ChronoIsle.exe`，并核对进程路径和响应状态。
