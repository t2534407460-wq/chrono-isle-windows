# 灵动岛交互、AI、工具页与通知修复设计

## 目标与范围

本次修复只覆盖用户指出的六项行为：

1. 音乐模式下点击灵动岛空白处不再触发音乐控制按钮闪烁，同时保留空白处展开/收起灵动岛的能力。
2. 移除 `LifeIslandWindow` 内全部可见鼠标悬浮提示，不删除无障碍名称。
3. 让 AI 的意图规划和命令参数输出稳定满足本地可解析契约，修复相对时间提醒的 `argument_invalid`。
4. 删除“今天”页中重复的“快问”和“取名”快捷按钮，在顶部“快问”旁新增纯文字“工具”页签；工具页提供可扩展的二级页签，首版只有“取名”。
5. 系统消息使用独立通知窗口，不受音乐模式阻塞；任务栏吸附时通知在灵动岛上方显示，其他位置在下方显示。
6. 删除灵动岛右键菜单上半部分的七个快捷入口：新建事项、添加提醒、专注模式、今天、月历、状态、快问。

不改变系统托盘菜单，不重做取名助手，不增加新设置项，也不修改现有发布产物。

## 音乐模式点击与悬浮动画

当前 Header 在鼠标按下时捕获指针。音乐区域因此可能收到临时 `MouseLeave`，随后在释放捕获时又收到 `MouseEnter`，控制按钮执行一次隐藏和显示动画，形成闪烁。

修复保留 Header 的单击展开和拖动逻辑，但在 Header 捕获鼠标期间不响应音乐区域的临时离开。释放捕获后，根据真实 `IsMouseOver` 状态决定是否隐藏控制按钮。已固定显示的控制按钮继续保持固定，不改变播放、暂停、上一首和下一首行为。

## 悬浮提示

删除 `LifeIslandWindow.xaml` 与 `LifeIslandWindow.xaml.cs` 中所有会生成 WPF `ToolTip` 浮窗的设置，包括：

- 折叠态导航、音乐波形和音乐按钮；
- 提醒关闭按钮、状态灯和网络状态；
- 歌手文本、日历节假日和事项详情提示。

`AutomationProperties.Name` 等无障碍信息保留，因此移除可视提示不会降低自动化与读屏语义。

## AI 可解析输出

故障日志显示，意图路由已经成功，失败发生在 `create_reminder` 参数解析与修复阶段。现有提示只给出 `"remind": null`，没有声明时间值必须包含 `localDate`、`localTime`、`relativeExpression`、`timeZoneHint` 和 `originalText`，模型可能返回合法 JSON 字符串或不完整对象，却无法通过本地命令契约。

DeepSeek 稳定 Chat Completions 接口支持 `response_format: {"type":"json_object"}`，该模式保证合法 JSON，但不保证符合自定义 JSON Schema。因此采用以下稳定接口兼容方案：

- 继续使用 `json_object`，不切换到 Beta URL，也不引入供应商专用的严格工具调用。
- 把每个操作的提示从 `null` 占位符改为完整嵌套结构示例，尤其明确时间、重复规则、目标和变更对象。
- 明确相对时间必须同时写入 `relativeExpression` 与 `originalText`。
- 在本地归一化层接受常见的标量相对时间，例如 `"十分钟后"`，转换为符合契约的时间对象，再执行现有严格反序列化和验证。
- 保留一次带验证错误的修复请求；修复后仍不合规时继续拒绝写操作。

测试直接覆盖“十分钟后提醒我测试”和精确嵌套结构，证明输出可以进入本地提醒管线，而不是只证明 JSON 能被解析。

## 顶部工具页与快捷按钮

顶部导航顺序变为“今天、月历、状态、快问、工具”。“工具”只显示文字，不带图标。

工具页是一个独立 Dashboard Panel，内部使用二级页签容器。首版只显示“取名”页签和取名助手入口；点击入口继续打开现有完整 `NamingWindow`，从而复用成熟的生成、候选切换和复制流程。后续新增工具时只增加二级页签，不继续挤占顶部导航。

“今天”页快捷操作保留“新建事项、专注模式、事项管理”，删除重复的“快问”和“取名”。

## 通知窗口

保留现有独立 `IslandNotificationWindow`：

- 不接管或替换音乐 Header；
- 新消息立即替换当前通知内容并重新开始五秒计时，不建立退出音乐模式后补播的队列；
- 窗口置顶、不可激活、从任务栏和任务视图隐藏；
- 自由位置和顶部吸附时显示在灵动岛下方；
- 任务栏吸附时以 Header 屏幕矩形为锚点显示在上方；
- 位置限制在当前显示器工作区。

新增契约测试，证明通知展示路径没有音乐模式条件，并覆盖任务栏 `placeAbove` 分支。最终发布后使用当前运行程序做真实新消息验证。

## 右键菜单

`CreateQuickActionMenu` 不再创建以下菜单项：

- 新建事项
- 添加提醒
- 专注模式
- 今天
- 月历
- 状态
- 快问

保留事项管理、设置、暂停提醒、勿扰模式、显示音乐模式和顶部吸附自动收缩。菜单分隔线随删除后的分组调整，不留下空分组。
