# 设置保存成功提示设计

## 目标

移除设置保存后的原生 Windows 信息框，改为与 ChronoIsle 圆角卡片、动态主题和强调色一致的窗口内成功提示，同时保留保存后自动关闭设置页的行为。

## 视觉设计

- 提示位于设置窗口右下方、底部按钮区域上方，不遮挡保存按钮。
- 使用 `Brush.Surface` 作为背景、`Brush.Accent` 作为描边和勾选颜色、`Brush.AccentSoft` 作为图标底色。
- 卡片使用 14px 圆角、轻量阴影和紧凑内边距。
- 内容为强调色勾选图标、标题“设置已保存”和辅助文字“更改已应用”。
- 所有颜色均使用动态资源，随主题模式和强调色实时变化。

## 交互

- 保存成功后禁用“取消”和“保存”按钮，防止重复提交。
- 提示以 160ms 淡入动画出现。
- 提示显示 900ms 后自动关闭设置窗口。
- 关闭前仍保持现有的偏好保存、主题提交、歌词刷新和提醒刷新逻辑。
- 其他具有确认意义的原生对话框不在本次修改范围内。

## 验证

- UI 契约测试确认主题化提示的结构、动态资源和文案存在。
- UI 契约测试确认保存处理器不再调用信息型 `MessageBox`，会显示提示、等待 900ms 后关闭。
- 运行现有核心测试和 UI 测试，发布并重新启动 win-x64 自包含测试版。
