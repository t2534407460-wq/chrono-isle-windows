# 删除歌词设置设计

## 目标

从设置窗口中删除已经不再使用的歌词相关配置：

- “从 LRCLIB 获取并缓存同步歌词”
- “歌词校准”滑块及数值

保留“播放音乐时在折叠岛显示歌曲信息”，不改变现有音乐模式。

## 实现

1. 删除 `LifeSettingsWindow.xaml` 中的两个歌词设置控件。
2. 删除设置窗口对 `LyricsEnabled`、`LyricsOffsetMs` 的加载和保存。
3. 删除设置窗口对 `LyricsService` 的构造注入以及保存后的刷新调用。
4. 保留偏好模型中的旧字段和歌词服务注册，确保已有偏好文件仍可读取，也避免扩大到媒体服务清理。

## 验证

- 契约测试确认设置窗口不再出现 LRCLIB、歌词开关或歌词校准控件。
- 契约测试确认设置窗口不再解析 `LyricsService`。
- 定向测试、全量测试和 Release 构建通过。
- 发布并重新启动本机程序，确认运行的是新产物。
