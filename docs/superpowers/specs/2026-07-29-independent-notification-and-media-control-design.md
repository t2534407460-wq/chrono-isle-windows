# 独立通知浮窗与音乐控制修复设计

## 目标

- Windows 通知不再接管灵动岛 Header，不受音乐模式、播放状态或折叠态刷新影响。
- 音乐播放期间新通知立即显示；退出音乐模式不会补播已处理通知。
- 网易云播放/暂停使用真实验证可双向工作的标准媒体键。
- 五柱波形最大高度为 20px；无音频时显示五个直径 4px 的圆点。

## 通知浮窗

采用独立 `IslandNotificationWindow`。窗口无边框、不可激活、不显示在任务栏、置顶并从任务视图隐藏。卡片宽 340px，使用项目现有 `Brush.Card`、`Brush.Stroke`、`Brush.Accent`、`Brush.AccentSoft` 和文本资源。

卡片左侧显示 28px 应用徽标，中间显示应用名标签、标题和最多两行正文。顶部、自由位置时显示在灵动岛下方；任务栏吸附时显示在灵动岛上方。位置限制在当前显示器工作区。

每条新消息立即替换当前内容，重新开始五秒计时，不建立待播队列。浮窗独立淡入/轻微位移动画，隐藏时淡出；不会改变主灵动岛宽度、高度、音乐控件或顶部收缩状态。

## 音乐控制

真实播放器验证结果：

- 网易云未暴露可用的 Windows GSMTC 会话。
- `WM_APPCOMMAND` 对网易云无效。
- `Ctrl+Alt+P` 可暂停但不能恢复播放。
- `VK_MEDIA_PLAY_PAUSE` 可以暂停和恢复，并成功恢复原状态。

因此网易云上一首/下一首继续使用现有有效快捷键，播放/暂停统一使用 `VK_MEDIA_PLAY_PAUSE`。点击按钮后不再先行反转图标，图标只根据随后检测到的真实播放状态更新。

## 波形

保留五根 4px 宽、圆角 2px 的主题色波形。无音频能量时高度为 4px，形成五个圆点；有音频时高度范围为 4–20px，所有柱随频段能量变化。

## 验收

- 播放和暂停状态下，网易云均能被灵动岛控制，按钮图标与真实状态一致。
- 音乐模式保持显示时，Windows 新通知在独立卡片中出现五秒。
- 通知结束或退出音乐模式后，不补播已经处理的旧消息。
- 主灵动岛尺寸不因通知改变。
- 静音时为五个圆点，播放时最高不超过 20px。
