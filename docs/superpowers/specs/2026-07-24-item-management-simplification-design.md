# 事项管理简化与中文语义

## 目标

让推荐能量和事项优先级使用易懂的中文；减少事项管理单行控件数量；从灵动岛快捷栏直接进入事项管理。

## 设计

- 灵动岛推荐能量下拉框显示为“低精力 / 中等精力 / 高精力”，内部仍使用现有 `EnergyLevel` 枚举。
- 事项管理优先级下拉框显示为“低 / 普通 / 高 / 紧急”，内部仍使用现有 `LifePriority` 枚举。
- 事项管理默认仅显示优先级与超时宽限（分钟）；分类、预计时长与能量放入“更多设置”展开区，保存行为和现有并发校验保持不变。
- 在灵动岛“问 AI”右侧加入“事项管理”按钮，复用已有管理窗口打开逻辑。

## 验证

- 下拉框显示中文，保存后枚举持久化值不变。
- 默认管理行不再出现多个空输入框；展开后可编辑原有附加属性。
- 新快捷按钮能打开事项管理窗口。
- 运行相关测试与完整构建检查。
