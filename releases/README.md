# 时屿 ChronoIsle 0.4.5

- `ChronoIsle-Setup-0.4.5-win-x64.exe`：Windows x64 自包含安装包，内置 .NET 8 运行时，安装到当前用户目录；程序启动仍按现有清单请求管理员权限。
- 首次启动默认深色（黑色背景）主题；升级保留已经保存的主题选择及用户数据。
- 修正知识库回答的图片地址截断与相对路径失效，补充被引用原文的配图，并直接预览当前远程知识库的鉴权图片。旧消息不改写，请重新提问查看完整图文回答。
- 保留本地/远程知识库问答、Markdown 与图片查看、图标修正、全页面布局及 Skill 按需同步行为。
- `SHA256SUMS.txt`：安装包 SHA-256 校验值，保留历史版本校验值。
- 历史安装包及便携包继续保留；本次仅生成 `0.4.5` 安装包。

本次沿用现有 Inno Setup 安装流程，不自动注册开发用 MSIX 稀疏身份包。全新设备的 Windows 系统通知接入仍需完成包身份注册与系统授权；模型与远程知识库访问凭据由使用者自行配置，安装包不包含个人配置或数据。

Release 自包含发布及 Inno Setup 构建通过，已核对安装包和组件版本、SHA-256 及发布目录未包含个人配置。本次 60 项相关服务测试、5 项发布契约、1 项真实远程图片双路径检查和 2 项聊天控件图片渲染检查通过。远程图片检查使用受控模型响应，不额外调用真实模型推理。

0.4.4 已记录的三项旧 UI 契约失败（事项工作台文案/入口、工具按钮 Tooltip）不在本次改动范围，本轮未重跑完整 UI 套件。当前状态：**已修改待测试**，全新安装、升级、卸载及实际操作待人工验收。

当前发布包未进行代码签名，Windows SmartScreen 可能显示安全提示。请仅从本仓库下载并核对校验值。
